# Mascots

Two brand birds, supplied by the team (AI-generated artwork owned by the
project — no third-party license involved):

- `mascot-empty.jpg` — plump bird with scarf. Used in every dataless
  state: Attached Files, History, Steps, Routes, no-workflow empties.
- `logout.jpg` — bird exiting through a door. Used in the logout farewell
  modal only.

Both are downscaled web copies (~480px, ~20KB). Bundled locally via Vite
imports (no CDN) so intranet deployments work. Original full-size files
were removed after installation — keep these two as the single family.
